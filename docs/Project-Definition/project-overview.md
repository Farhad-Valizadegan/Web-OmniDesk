# Project Overview



> Status: Draft



## Project Name



OmniDesk



## Project Type



Web-based unified communication workspace.



## Overview



OmniDesk is an integrated and intelligent workspace for managing communication across multiple platforms.



The system brings communications from services such as Gmail and Telegram into one environment, allowing users to view, search, organize, and manage their messages and conversations.






## Initial Product Vision



Provide users with one intelligent workspace for managing multiple communication channels while reducing context switching between separate platforms.



## Initial Integrations



- Gmail

- Telegram



Additional communication providers may be supported in future versions through an extensible connector architecture.



## Primary User



The initial target user is an individual who manages communication across multiple platforms.
