# Project Goals and Objectives



> Status: Draft



## Project Goals



The main goals of OmniDesk are to:



1. Provide a unified workspace for managing communication from multiple platforms.

2. Reduce context switching between separate communication applications.

3. Provide a consistent way to view, search, and organize messages and conversations.


5. Establish an extensible foundation for adding additional communication providers.

6. Demonstrate professional Software Engineering practices through a complete portfolio project.



## Initial Project Objectives



The initial version of OmniDesk should aim to:



- Allow users to access the application securely.

- Allow users to connect supported communication accounts.

- Retrieve and display messages from Gmail and Telegram.

- Present messages through a unified communication interface.

- Allow users to search, filter, and organize available messages.




- Process synchronization tasks asynchronously when appropriate.


- Protect authentication credentials, tokens, and sensitive communication data.

- Include automated tests for critical application workflows.

- Provide reproducible setup and deployment documentation.



## Portfolio Objectives



The project should demonstrate practical knowledge of:



- Software Development Life Cycle management

- Requirements Engineering

- System Analysis

- Software Architecture and Design

- API and External-System Integration

- Database Design

- Security Engineering

- Automated Testing

- DevOps and Deployment

- Agile and Incremental Development

- Technical Documentation



## Goal-Objective Relationship



The goals describe the desired outcomes of the project. The objectives describe the concrete capabilities and engineering results that will help achieve those goals.
