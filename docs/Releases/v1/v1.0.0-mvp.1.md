# OmniDesk v1.0.0-mvp.1

> Status: Released pre-release
> Release date: 2026-10-02

## Purpose

This pre-release presents the verified OmniDesk MVP before the final `v1.0.0` release. Creating this document does not create a Git tag or GitHub release.

## Included Scope

- Registration, password login, CAPTCHA, and email one-time-code verification
- Gmail authorization, synchronization, search, and message display
- Per-user Telegram connection with phone, code, and optional two-step password
- Read-only Telegram chat and message access through isolated TDLib runtimes
- Telegram photos, videos, voice messages, and profile photos where the source account and adapter can retrieve them
- Focused workspace UI with provider-specific views

## Verified MVP Evidence

- Real Telegram authorization, chat/message retrieval, supported media loading, and refresh recovery passed on 2026-10-01.
- Gmail authorization and inbox loading passed in the configured development environment.
- Automated backend and frontend suites verify owner isolation and the core provider flows without storing real credentials or private message content in the repository.

## Excluded Scope

- Provider message sending
- Starred, custom Labels, and Settings views
- Paid external model services or assisted-generation features
- Production hosting guarantees

## Known Limitations

- Telegram depends on the local TDLib adapter, server-level application credentials, and a valid session for each connected user.
- Gmail requires valid Google OAuth credentials, an exact callback URL, and a configured mail delivery service for login codes.
- Some provider media may remain unavailable when Telegram or Gmail does not expose the source file to the connected account.
- This pre-release requires final security, deployment, and manual end-to-end checks before promotion to `v1.0.0`.

## Release Gate

Publish only after backend tests, frontend tests, lint, production build, migration checks, documentation links, secret scanning, and the core login/Gmail/Telegram user journeys pass.
