# Version 1 Releases

OmniDesk Version 1 is currently available as an MVP pre-release. Release notes document completed work; they do not imply production readiness or expanded future scope.

- [v1.0.0-mvp.2](./v1.0.0-mvp.2.md) — 2026-10-12: HUD interface, bounded authentication requests, and Telegram loading recovery.
- [v1.0.0-mvp.1](./v1.0.0-mvp.1.md) — 2026-10-02: first released MVP with Gmail and read-only Telegram integration.

Future stable or feature releases should document delivered changes, validation, upgrade and rollback steps, and known limitations. Publish only after the relevant checks and GitHub CI pass.
