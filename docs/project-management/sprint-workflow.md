# Sprint Workflow



> Status: Draft



## Purpose



This document describes the standard workflow used to plan, execute, verify, and complete an OmniDesk AI sprint.



## Workflow



![OmniDesk AI Sprint Workflow](./diagrams/sprint-workflow.svg)



## Sprint Activities



1. Review the approved milestone outcome.

2. Refine the product backlog.

3. Select backlog items for the sprint.

4. Define the sprint goal.

5. Define acceptance criteria.

6. Break selected items into implementation tasks.

7. Implement the selected work.

8. Run automated tests.

9. Run quality and security checks.

10. Review the sprint increment.

11. Record sprint completion when all criteria are satisfied.



## Completion Rule



A sprint is complete only when:



- Its sprint goal is achieved.

- Acceptance criteria are satisfied.

- Relevant tests pass.

- Quality checks pass.

- Security considerations are addressed.

- The increment is reviewable.

- The sprint status is recorded.



## Release Relationship



A sprint produces a reviewable increment.



A sprint does not automatically create a release.



A release requires a separate review of milestone outcomes and release criteria.
