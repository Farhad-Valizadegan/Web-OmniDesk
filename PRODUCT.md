# Product

## Platform

web

## Product Purpose

OmniDesk brings Gmail and read-only Telegram communication into one authenticated workspace.

## Capabilities and Constraints

Laravel backend, React/TypeScript frontend, PostgreSQL, and provider adapter boundaries.
Existing registration, login verification, CAPTCHA, Gmail authorization/synchronization,
Telegram authorization/history/media, search, filtering, and ownership isolation must remain intact.
Sending messages, Starred, custom Labels, Settings, and AI generation remain outside the MVP.
Local backend for this project: http://127.0.0.1:18001.
The repository is private and project-owned code uses a proprietary notice.

## Brand Commitments

The user requests neo-brutalism combined with sci-fi HUD styling in light and dark modes.
The user chose a dense sci-fi control room with stronger glow and animation, built directly in the app.
Visibility and readability are explicit priorities, alongside transparency, motion, graphics, graphs, and diagrams.

## Evidence on Hand

README.md, frontend/README.md, backend/routes/api.php, frontend/src/lib/api.ts,
and docs/Releases/v1/v1.0.0-mvp.1.md describe the implemented MVP.
Provider data must come from existing APIs. No invented activity or operational measurements.

## Open Decisions

A narrower primary-user persona has not been established. The design supports the existing communication workflows.
